# anime-wallpapers

A clean anime wallpaper website with a search feature, category filters, and download buttons for desktop and mobile wallpapers.

## Project setup

```bash
npm install
npm run dev
```

Then open:

```bash
http://localhost:3000
```

## Features

- Mobile and PC wallpaper categories
- Search by title or tags
- Download button for each wallpaper
- Dark anime-inspired design
- Responsive layout

## Notes

This project uses public images already uploaded to the repository and loads them directly from GitHub raw URLs.
